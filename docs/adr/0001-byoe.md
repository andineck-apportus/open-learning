# ADR 0001: Bring Your Own Everything (proposed)

Status: Proposed; not implemented.

- Identity: Google / Microsoft OAuth.
- Storage: user-owned Google Drive / OneDrive with versioned JSON documents and immutable learning events; IndexedDB offline cache.
- AI: pluggable providers with user-managed credentials via secure mechanism, never browser-exposed API secrets.
- Concurrency: optimistic version checks, idempotent event IDs, conflict handling, durable retry queue.
- Privacy: explicit consent, minimal OAuth scopes, no shared public learning data, export/delete functionality.
- Avoid central learner database initially, but revisit if synchronization and analytics become harder than a managed database.
- MVP sequence: local learning -> photo review -> OAuth/storage -> secure AI integration -> robust offline sync -> broader subjects.
